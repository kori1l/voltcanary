# Design

Keep failed preparation linked to its durable task: execution terminal states
still prevent reuse, but a technical preparation failure does not erase pending
dashboard intent. Name-only answers continue through the selected owned review.

The existing schema generator supplies dataRef enums from the current authorized
capability projection. Initial composition excludes operations requiring an
existing review; refinement and stored legacy execution remain compatible.
Compilation still performs all normal resource/contract checks.
Renewed dataRef values include at most12 ASCII characters of field-key hint, a
short field/metric family label and their existing random namespace. Hints are descriptive, never authority or a
fallback matching rule; exact current refs are still required. Keep refs under40
characters to preserve the bounded model-context budget.

Use the existing trace recorder for bounded response status, configured limit,
numeric token usage and final-text presence. Do not record hidden reasoning,
headers, credentials or raw output. Observation does not introduce retries.

Replay the existing independent corpus predicates via conversation submission.
Keep each conversation and trace export alongside each trial; preserve failures,
including transport/dependency failures. Test resources use clear QA names,
ordinary authentication and ordinary decommission/archive workflows. Do not
modify preexisting user dashboards. Separate compiler, interpretation, provider,
fixture and visual failures. Stage5/6 work and default-enable gates remain deferred.
