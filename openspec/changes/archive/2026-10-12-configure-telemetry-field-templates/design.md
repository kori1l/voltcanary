# Design

Owner-scoped versioned templates contain up to 32 rules: canonical metrics-relative dotted path, stable key, label, type number/string/boolean, unit, store and display defaults. No script or arbitrary JSONPath execution. Templates can bind selected owned sources or all owned sources of a selected device type. Assignment snapshots policy into source mapping and emits existing runtime config events; editing a template updates assigned sources transactionally. Sources without templates retain legacy behavior. Clearing assignment restores legacy collection. GPS storage requires both coordinates and transport projection requires coordinates; stored typed context can stand alone without a GPS projection.

Authenticate source before policy evaluation. Internal source reconciliation includes mapping so policy survives ingestion restart/cache refill. Filter before accepted event publication, idempotency and storage. Configured values carry bounded type/label/unit metadata under a reserved configured-fields object; dropped inputs are not copied into raw readings, positions or numeric series. Validate canonical GPS bounds and configured values on HTTP and broker. Invalid configured values reject a message; absent values are omitted, false/zero preserved. Empty selection causes an explicit filtered result without publishing. Numeric fields use existing time-series storage; generic text/bool values remain typed JSON. Keep custom fields out of automatic analytics until separately supported.

Typed latest fields API preserves source and observation time; UI adds a compact table to telemetry. Chart discovery includes stored configured numeric series. Map points carry configured values; presentation mapFields is an optional list, undefined means defaults and empty means no detail fields. Choose fields from bound device evidence and retain unavailable selections without inventing values. Selection changes presentation only, never retention. Templates can be reused across tram/bus and other device types. No guessed sensor readings or device-specific branches.

Verify authorization, isolation, template edits and bulk assignment, filtering at ingress and persisted storage, custom types/paths, false/zero, GPS pair constraints, legacy behavior and history preservation. Deploy and verify real HSL observations and browser configuration/presentation.
