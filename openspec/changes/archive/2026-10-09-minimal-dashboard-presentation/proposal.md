## Why
Users want charts and values rather than permanent technical text and repeated navigation rows. Presentation annotations should be optional settings.
## What Changes
- Default to charts/values without normal status, captions, provenance and calculation paragraphs.
- Add explicit panel presentation toggles and on-demand information in a right drawer.
- Put screen selection and editor actions in one compact header; retain multiple working screens.
- Preserve visible exceptional state badges and accessible chart descriptions.
## Capabilities
### New Capabilities
- `minimal-dashboard-presentation`: optional panel annotations and minimal workspace chrome.
### Modified Capabilities
## Impact
Frontend rendering and existing presentation JSON only; evidence APIs, calculations and access controls are unchanged.
