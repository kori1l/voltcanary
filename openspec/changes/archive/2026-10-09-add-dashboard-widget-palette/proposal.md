## Why
Adding a widget through a type dropdown and placement form does not match the direct grid editing workflow. Users need a visible palette of visual cards that can be dragged to the canvas.
## What Changes
- Add a searchable, nonmodal widget palette beside the editor canvas with visual type previews and capability explanations.
- Use the grid library's external drop preview for snapped size and placement, then open configuration for the inserted panel.
- Keep click-to-add for keyboard/mobile and explicit relative placement as a secondary command.
## Capabilities
### New Capabilities
- `dashboard-widget-palette`: Visual drag-to-add catalog.
### Modified Capabilities
## Impact
Frontend dashboard editor, grid external drop integration and workflow docs; no API or definition format changes.
