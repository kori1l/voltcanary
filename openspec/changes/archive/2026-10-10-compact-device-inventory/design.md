# Design

Alert summary caching records only successful reads and resets on effect cleanup. StrictMode replay must initiate a replacement read after invalidating the initial request, so the summary and Refresh button cannot remain loading after successful server responses.

Alerts use one toolbar above a compact count strip; duplicate prominent-incident summary, full-width sorting/refresh fields and separated Inbox/Rules panels are removed. The actual inbox retains severity sorting, source evidence and incident actions. Maintenance filters move from the vertical rail into a top toolbar, preserving interval/filter/page query semantics. Shared CompactEntityFilter preserves paged authorized lookup and keyboard/outside dismissal without consuming normal layout height.

Simulator presets are read only when simulator setup or Demo Tools is active. A local icon reflects the reference read (available/unavailable/checking/unchecked), distinct from runtime execution; failed reads have a local retry. Existing Compose simulator service is started locally. Setup recovery gates the Add action synchronously while a saved account checkpoint awaits restoration, fixing the transient enabled-button race caught by the full frontend suite.

Primary location/status filters are visible beside search/view in the top row. Paged location search opens in an anchored popover; read-refresh settings open under Options, without shifting the device board. This implements the user's explicit request to move filters upward compactly.
DevicesPage remains a route shell and delegates search/filter/view presentation to a focused DeviceInventoryControls component. Search, location, status and view stay visible in a compact top row. Paged location lookup and read-refresh controls open in anchored popovers; active filters retain their selected values and a clear action. Reference read failures are disclosed once in a compact expandable warning without blocking successfully loaded inventory. Refresh reloads inventory and references. Page navigation is shown only for multiple pages; visible counts identify the current page rather than inventing a fleet total. Room sections form responsive columns and healthy evidence timestamps are not duplicated under each card. Only the risk read for an already authorized inventory device maps HTTP 404 to empty evidence, with 'Risk not calculated'; 403 and network/server failures retain existing isolation, data purging and retry behavior.
