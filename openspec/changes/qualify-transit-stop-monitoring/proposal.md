## Why

A convincing chat or live map is not proof of correct missed-service detection, resumable setup or economic multi-model execution. The scenario needs independent event outcomes, negative cases and measured complete-task quality.

## What Changes

- Freeze independent event and dialogue corpora with exact source/device/trip/stop/rule/dashboard assertions.
- Measure deterministic detection, restart/replay/late correction, browser-closed evaluation, access safety and bounded pilot capacity.
- Separate offline fixtures, real-feed compatibility and explicitly authorized real-model/profile trials; keep complete first-pass/recovered/final and cost accounting.

## Dependencies

Harness/contracts can start with this proposal. Final qualification consumes T1–T6 and retains existing A5/V/R/A6 acceptance ownership; it does not create a cycle requiring qualification before implementation.
