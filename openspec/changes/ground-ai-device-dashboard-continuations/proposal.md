## Why

a dashboard task with an empty device selection and no dashboardDataChoices. The
model invented location/speed/fuel/temperature refs; compilation rejected them three
times. A separate creation attempt leaked a sanitizer instruction to the user.

## What Changes
- Resolve follow-up references from durable confirmed execution results, with explicit
  selection changes and genuine ambiguity handled without guessing.
- Obtain actual selected-device data and compatible widget capabilities before
  dashboard generation; never repair an absent selection by inventing refs or fields.
- Repair uniquely recoverable device-output format faults internally; present concrete
  user choices only for missing meaning, and truthful technical failures otherwise.
- Verify the whole creation/connection/dashboard conversation, including recovery.
